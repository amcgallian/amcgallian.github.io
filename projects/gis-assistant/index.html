GIS Assistant

An automated pipeline that harvests, cleans, and tags geodata metadata from the UChicago ArcGIS Online environment into a searchable catalog and geoportal dashboard.

Client UChicago Center for Digital Scholarship Stack Python · SQLite · Flask

Overview

The UChicago ArcGIS Online environment hosts hundreds of geodatasets contributed by researchers, library staff, and students across the university. Without consistent metadata tagging, finding relevant layers is difficult — items are inconsistently named, described, and tagged.

GIS Assistant is a curation pipeline that automatically harvests item metadata via the ArcGIS REST API, normalizes and cleans the records, and applies a controlled vocabulary of tags to improve discoverability. Results are stored in a SQLite database and surfaced through a lightweight Flask geoportal dashboard.

Context

Developed as part of my Data Visualization Fellowship at the UChicago Library, in support of the Center for Digital Scholarship's geodata discoverability initiative.

Pipeline

harvest_arcgis.py — Metadata collection
Queries the ArcGIS Online REST API to pull item records (title, description, tags, owner, date, type) into a raw SQLite table.
clean_catalog.py — Normalization
Deduplicates entries, normalizes field values, strips boilerplate text, and flags items with missing or inadequate metadata.
tag_catalog.py — Controlled tagging
Applies a controlled vocabulary to each item based on title, description, and layer type — supporting themes like hydrology, demographics, and transportation.
catalog_pipeline.py — Orchestration
Runs the full harvest → clean → tag sequence and reports summary statistics on catalog completeness.
geoportal_proj/ — Dashboard
Flask web app that reads the curated SQLite database and exposes a searchable, filterable interface for browsing the catalog.

Databases

The project maintains two SQLite databases:

  • camel_cache.db — raw harvested records and intermediate processing state
  • isac_geodata.db — cleaned, tagged, production-ready catalog entries

Impact

The catalog pipeline substantially reduced the manual effort required to maintain the UChicago geodata inventory. The geoportal dashboard gives library staff and researchers a single interface for browsing and auditing the full ArcGIS Online catalog with faceted filtering by theme, data type, and completeness score.
