Publication Cartography · Reproducible Pipeline

North Syrian Inscriptions Map

A reproducible geocoding pipeline and publication map locating Hieroglyphic Luwian and Semitic Alphabetic inscription findspots across Anatolia and North Syria, built for Cory Crawford (Ohio University) for one of his publications.

Findspots ~72 inscriptions Gazetteer 2,910 candidate points Output 600 DPI, colour + greyscale

Overview

Built for Cory Crawford (Ohio University), whom Andrew met through the Türkmen-Karahöyük Archaeological Project (TKAP), as a publication map for one of his papers. The source list of ~72 Luwian and Semitic Alphabetic inscription sites had names but no coordinates. The only available gazetteer covering the region — a general Ancient Near East KMZ file — had coordinates but 2,910 points and no reliable index by inscription type. The project's job was closing that gap: matching each named site against the gazetteer and producing a clean, sourced point layer ready for cartography.

The matching problem

Ancient Near East sites are routinely referred to by multiple names — an ancient name, a modern name, sometimes both in the same gazetteer entry formatted as Ancient Name (Modern Name) or with alternates separated by slashes. The pipeline splits each gazetteer entry into its name variants before matching, so a site named one way in the inscription list still resolves against a gazetteer entry recorded under a different name.

Pipeline

Built as a single reproducible Jupyter notebook — every step from parsing to validation runs as a documented, re-runnable cell, so the match can be re-checked or extended later without reconstructing the process from memory. The notebook's job stops at producing a clean, correct site table; the final cartography (basemap, hillshade, symbology) was done separately in QGIS.

Output

The sourced dataset ships as CSV, GeoJSON, and GeoPackage. The final publication map was produced in QGIS with custom hillshade and DEM styling and label conventions matching published academic convention (unbracketed = modern name, bracketed = ancient name, underlined = archaeological site), exported at 600 DPI in both colour and greyscale.
