TKAP Tools

A QGIS plugin built and published for the Türkmen-Karahöyük Archaeological Project, used in the field by an international excavation team.

Stack Python · PyQGIS Requires QGIS 3.34+ License GPL-2.0
GitHub → Docs →

Overview

Excavation teams collect survey points in the field with Emlid GNSS receivers, but turning raw points into the polygons, phase plans, and section drawings archaeologists actually use was a manual process. TKAP Tools automates that pipeline inside QGIS, and ships to the field team through a self-hosted plugin repository so updates install the way any other QGIS plugin does — no manual file copying required.

Three tools

Survey Points to Polygons
Builds stratigraphic unit (SU) and Feature polygons directly from Emlid GNSS point exports.
Stratigraphic Phasing
Splits SUs into one layer per excavation phase and exports phase plans for the field team.
Section Drawing
Draws stratigraphic sections directly over a rectified photo of the excavated wall face.

Distribution

The plugin installs from a self-hosted repository at amcgallian.github.io/tkap-qgis/plugins.xml, so the field team gets version updates automatically through QGIS's own Plugin Manager rather than needing a new zip file each season.

Related work — Archaeolog Webmap

Contributor project — code not public, part of a larger system that isn't mine to share.

Rebuilt the map layer for Archaeolog, a dissertation-scale archaeological records system built by labmate Dominik Lukas. Delivered a Vue + OpenLayers rewrite of the map view, its backing API routes, the symbology system, map-based selection tools, and Harris matrix links surfaced in map popups — the piece of the system excavators and lab teams used daily to understand the spatial relationships between finds, samples, and the trenches they came from. Archaeolog itself is Lukas's project; this was independent ownership of its mapping layer, not the system as a whole.
