Chicago Environmental Atlas

A Flask web application mapping 150 years of Chicago environmental change — land surface temperature, vegetation, hydrology, and biodiversity — built for the Data Visualization Fellowship.

Coverage 1870 – 2025 Stack Flask · Docker · Leaflet · Vega-Lite Data ~10 GB processed
GitHub →

Currently self-hosted and offline between demos — a walkthrough recording is linked below.

Overview

The atlas layers historical maps, Landsat satellite imagery, and public environmental datasets onto a single interactive map, with a timeline slider that drives every layer to the selected date at once. Vector layers — historical city boundaries, waterways, species observations, water quality, and weather stations — filter to match, while Landsat rasters swap between land surface temperature and vegetation index tiles.

Getting there meant georeferencing historical Chicago boundaries by decade back to 1870 and assembling Landsat coverage across five decades into a consistent, analysis-ready set of tiles — most of the actual work behind the project.

Features

Timeline-driven map
Scrub from 1870–2025; Landsat rasters and vector layers update together to the selected date.
Analysis panel
Vega-Lite charts (histogram + time series) alongside the map, with a draw-your-own-area tool for regional summaries.
Data portal
Searchable layer cards with citations, temporal coverage, and GeoJSON downloads for every dataset.

Deployment

Packaged with Docker Compose for a reproducible build. Presently self-hosted rather than running on a paid always-on server — a recorded walkthrough is the reliable way to see it working until that changes.
