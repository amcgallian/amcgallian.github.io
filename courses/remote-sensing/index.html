Introduction to Remote Sensing

Satellite image acquisition, preprocessing, and analysis — from electromagnetic theory through applied Landsat thermal band processing and land cover classification.

Course Overview

Introduction to Remote Sensing covered the full pipeline from electromagnetic radiation physics through applied analysis of multi-spectral satellite imagery. Emphasis was placed on Landsat data, thermal band processing, and practical QGIS/Python workflows.

Key Topics

Electromagnetic Spectrum & Sensor Physics

Foundations of how satellite sensors record reflected and emitted radiation across different spectral bands — visible, near-infrared, shortwave infrared, and thermal infrared. Radiometric calibration and atmospheric correction concepts.

Landsat Data Processing

Hands-on processing of Landsat 8/9 imagery — accessing USGS data archives, converting digital numbers to top-of-atmosphere reflectance, and computing common spectral indices (NDVI, NDWI, NBR).

Thermal Band Analysis

Land surface temperature (LST) retrieval from Landsat thermal bands. Processing involved extracting radiometric calibration constants, converting thermal band values to at-sensor brightness temperature, and applying split-window corrections.

Applied directly in the Environmental Fellowship

Thermal band processing skills developed here were directly applied in the EF project's Landsat temperature extraction pipeline, and later integrated into the Chicago Environmental Atlas as the land surface temperature data layer.

Land Cover Classification

Supervised and unsupervised land cover classification using multi-spectral imagery. Training sample collection, maximum likelihood classification, and accuracy assessment with confusion matrices.

Change Detection

Multi-temporal analysis to detect land cover change — image differencing, post-classification comparison, and change vector analysis applied to real before/after datasets.

Course Project

An independent remote sensing analysis project applying course methods to a self-selected study area and research question. Scripts and analysis outputs are in the project archive.
