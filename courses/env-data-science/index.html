Environmental Data Science

Spatial analysis, biodiversity informatics, and reproducible computational workflows applied to real-world environmental datasets.

Course Overview

Environmental Data Science introduced graduate-level methods for working with spatial and ecological data computationally. The course emphasized reproducibility, open data standards, and real-world application across several thematic labs.

Lab Work

Biodiversity Data (W2)

Introduction to biodiversity informatics using GBIF occurrence records. Covered data access via APIs, cleaning occurrence data, handling spatial uncertainty, and visualizing species distributions.

Vector Spatial Analysis (W4)

Geoprocessing with GeoPandas — spatial joins, overlays, buffer analysis, and dissolve operations. Applied to real Chicago community area and infrastructure datasets.

Raster Analysis (W6)

Raster data models, coordinate systems, and analysis with Rasterio. Topics included resampling, masking, zonal statistics, and raster algebra for environmental metrics.

Species Distribution Modeling (W7)

Introduction to species distribution modeling — presence/background sampling, environmental predictors, and model evaluation. Applied MaxEnt-style approaches using spatial Python tools.

Reproducible Workflows (W8)

Final lab focused on building reproducible, documented analysis pipelines — environment management, notebook discipline, and sharing geospatial analysis code.

Class Projects

CAWS — Chicago Area Waterway System

Team project analyzing water quality across the Chicago Area Waterway System (CAWS) using Metropolitan Water Reclamation District (MWRD) monitoring data. The project computed a composite Water Quality Index (WQI) and Habitat Morphology & Physical Index (HMPI) across monitoring stations, joining these to spatial geometries for choropleth mapping of waterway health across Chicago's interconnected canal network.

Autumn 2025. Collaborative project combining data wrangling, spatial join operations, and communication-focused visualization.
